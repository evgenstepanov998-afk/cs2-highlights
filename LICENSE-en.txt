1. WHAT THE SOFTWARE DOES
1.1. The Software reads a Counter-Strike 2 demo file chosen by the User, starts a separate copy of CS2 on the User's computer through the HLAE tool and records video clips of the chosen players' moments.
1.2. While recording, the Software starts CS2 in -insecure mode (VAC is off in that mode and this copy cannot connect to game servers), hides the game window and temporarily lowers the in-game volume of CS2; graphics stay as the User set them by default and are lowered only in "Fast" mode. After recording the game settings are put back, also at the next Windows sign-in if the computer turned off during recording. The Software does not change Windows sound settings and does not touch a copy of CS2 the User starts on their own.
